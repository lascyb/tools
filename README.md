# 🛠️ Tools - 实用工具箱

一个基于纯前端的实用工具集合，所有处理都在本地完成，保护您的隐私安全。

## ✨ 特性

- 🔒 **隐私安全** - 所有处理都在浏览器本地完成，数据不上传服务器
- 🚀 **即开即用** - 无需安装，打开即用
- 💻 **纯前端** - 基于 HTML、CSS、JavaScript，无需后端支持
- 📱 **响应式设计** - 完美适配桌面和移动设备
- 🎨 **现代化 UI** - 美观简洁的用户界面

## 🎯 工具列表

### 🖼️ 图片压缩工具

支持 JPG、PNG、WEBP 格式的图片压缩工具。

**功能特性：**
- 可调整压缩质量（10%-100%）
- 支持自定义最大宽度和高度
- 实时预览压缩效果
- 显示压缩率和文件大小对比
- 支持拖拽上传

1. 克隆仓库

2. 直接双击打开 `index.html` 文件即可使用
